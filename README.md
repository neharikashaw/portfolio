# Neharika Shaw — Accounting & Taxation Professional Portfolio

A personal portfolio website for **Neharika Shaw**, an Accounting & Taxation Professional with 1+ years of audit experience, practical exposure in balance sheet preparation, GST & TDS compliance (Forms 24Q & 26Q), income tax return filing, and financial statement finalization.

## 🌟 Highlights
- **Framework**: React.js with Vite
- **Styling**: Pure CSS with custom CSS variables & editorial luxury design system
- **Typography**: Cormorant Garamond / Playfair Display & Manrope / Inter
- **Color Palette**: Deep Navy (`#142B3B`), Warm Ivory (`#F8F6F0`), Muted Gold (`#B89A62`)
- **Key Sections**:
  - Hero with professional portrait showcase
  - About & professional journey
  - Domain expertise (Balance sheets, TDS, GST, ITR, Audits, Software)
  - Career timeline at R.P. Boobna & Co. Chartered Accountants
  - Education (B.Com. University of Calcutta, Higher Secondary, Secondary)
  - Competency matrix (Accounting, Taxation, Tools like Tally & KDK Spectrum, Languages)
  - Hobbies & Pursuits
  - Contact section with direct messaging
  - Interactive & printable Curriculum Vitae modal and standalone PDF/print export

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/neharikashaw/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
```
